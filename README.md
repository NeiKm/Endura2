## 🚀 Запуск

Перед запуском убедись что виртуальное окружение Endura2Interpretator используется,
Так же проверь что находишься в папке Endura2

Затем введи данную ниже комманду в терминал

```bash
python launcher.py
```

`main.py` лучше не трогать без знания о проекте, а то и игру поломать можно)👀
